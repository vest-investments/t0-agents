# Security Policy

## Supported versions

Fixes land on `main` and ship in the next release of the latest minor
version. Older minors do not receive backports.

## Report a vulnerability

Report privately through [GitHub private vulnerability reporting](https://github.com/vest-investments/t0-agents/security/advisories/new).
Please do not open a public issue, pull request or discussion for a
vulnerability.

You will get an acknowledgement within three business days, and an
assessment with a planned fix or a reason for declining within ten.
Credit in the release notes is yours unless you ask otherwise.
